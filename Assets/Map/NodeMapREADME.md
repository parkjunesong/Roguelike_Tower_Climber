# 랜덤 탐사 맵 설정

- `CaveNodeMap.asset`의 Size는 M × M 방 개수입니다. 각 방의 길이는 Map Prefab의 `ExplorationMap.width`를 사용합니다.
- 탐사 시작마다 맵을 생성합니다. Use Fixed Seed를 켜면 Seed로 같은 맵을 재현할 수 있습니다. 생성 결과는 원본 SO를 변경하지 않습니다.
- 시작방과 보스방을 각각 하나 생성합니다. 모든 방은 상하좌우 한 칸의 양방향 길로 연결되어 도달할 수 있습니다. Extra Connection Chance는 기본 연결 외의 추가 길 확률입니다.
- Event Node Chance로 일반 방의 이벤트 확률을 설정합니다. Encounter Enemies에 잡몹 UnitData를 넣고, 선택지의 Random Encounter를 켜면 조우마다 목록에서 한 적을 무작위 선택합니다. 기존 Battle 입력도 유지하며, 두 입력이 모두 비어 있으면 계속 탐사합니다.
- 탐사 진입은 반드시 Main의 파티 편성 패널을 거칩니다. 슬롯을 클릭해 최대 3명 중 최소 한 명을 편성하고 탐사 시작을 누릅니다. 캐릭터 후보는 Main의 `PartyFormationController.availablePlayers`에 지정합니다. 현재 테스트 후보는 Player이며 여러 슬롯에 선택할 수 있습니다.
- 편성 화면에서 생성한 런타임 Unit을 `PlayerParty.Create`로 전달하고 `ExplorationEntry`가 탐사 씬에 넘깁니다. 탐사 씬은 유닛을 생성하거나 BattleData.Players로 대체하지 않습니다. explore 씬을 직접 실행해도 먼저 편성 화면으로 이동합니다. 시나리오 외 진입에는 `ExplorationEntry.Begin(mapData)`를 사용하세요.
- 시나리오에서 Battle 씬으로 바로 진입하면 `BattleData.Players`로 해당 전투의 유닛을 새로 생성합니다. 빈 슬롯은 건너뛰며 플레이어가 최소 한 명 필요합니다. 이 경로는 탐사 전역 파티를 사용하거나 초기화하지 않습니다. 탐사 보스 및 고정 전투의 BattleData는 Waves만 사용합니다.
- 새 탐사 편성을 확정하면 기존 탐사 파티를 정리하고 선택한 파티로 교체합니다. 편성 취소는 기존 파티를 변경하지 않습니다. 같은 탐사 안에서는 체력, UnitStatus, 장비, 사망 상태를 보존하며 잡몹 조우와 보스전 모두 같은 유닛을 사용합니다. 파일 저장/불러오기는 구현 범위에 포함되지 않습니다.
- 이벤트 선택지는 방 중앙(`width / 2`)에서 표시됩니다. 준비 후 다시 선택하려면 중앙에서 E를 누릅니다. 오른쪽 끝에서는 지도가 자동으로 열리며, 닫은 뒤 E 또는 M으로 다시 열 수 있습니다. I는 인벤토리를 열고 닫습니다. 왼쪽 가로형 캐릭터 사이드바를 클릭하면 해당 캐릭터의 정보창(무기·방어구·스탠딩·현재 능력치)을 엽니다. 정보창은 인벤토리에서 열 수 없으며 두 창 중 하나만 표시됩니다. X 또는 Esc로 닫습니다. 전투 중에는 사이드바가 숨겨지고 종료 후 복귀합니다.
- UnitData의 Portrait와 Standing Illustration으로 UI 전용 이미지를 지정할 수 있습니다. 미지정 시 현재 캐릭터 스프라이트를 사용합니다. 현재 능력치는 실제 UnitStatus.GetFinalStat 값을 표시합니다.
- 방어구는 ItemDefinition의 Armor Part를 Hat(모자), Top(상의), Bottom(하의), Shoes(신발)로 지정합니다. 착용한 방어구 아이콘은 사이드바 HP바 위에 표시됩니다. 인벤토리 장비를 Party HUD 캐릭터 카드에 드래그하여 장착하며, 같은 부위의 기존 장비는 새 장비의 인벤토리 칸으로 돌아갑니다. 무기도 같은 방식으로 교체됩니다. 캐릭터 정보창의 장비를 창 밖으로 드래그하면 인벤토리로 돌아가며, 인벤토리가 가득 차면 해제되지 않습니다. 창 안에 놓거나 드래그 중 창을 닫으면 이동을 취소합니다. 좌클릭 정보 표시는 유지하고 탐사 중 우클릭 메뉴와 장착 대상 선택창은 사용하지 않습니다.
- 장착 장비의 능력치는 UnitStatus.GetFinalStat에 합산되며 교체·해제 즉시 반영됩니다. 최대 체력 증가로 회복되지는 않고, 최대 체력이 감소하면 현재 체력이 새 최대치를 넘지 않도록 조정합니다. 기본 UnitData와 ItemDefinition SO는 수정하지 않습니다.
- 지도에는 현재 방과 길로 연결된 상하좌우 한 칸 방이 보입니다. 방문한 방과 실제로 지나온 길은 거리와 관계없이 계속 표시되며, 미방문 일반 방만 시야 밖에서 안개 처리됩니다. 시작방·보스방 위치는 항상 보이지만 미탐사한 먼 길은 공개하지 않습니다. 지도 위에서 휠로 확대·축소하고 좌클릭 드래그로 이동합니다.
- 전투는 explore 씬의 같은 방에서 진행합니다. 아군 → 스킬 → 대상 순서로 선택하며, 다음 턴 버튼도 제공합니다. 기존 전투 스킬 UI와 유닛/효과 시스템을 사용합니다.
- 이벤트 전투 승리 또는 전투 없는 선택지는 해당 노드에서 다시 발생하지 않습니다. 보스 격파 후 탐사 완료 버튼이 활성화됩니다. 패배하면 결과창에서 탐사를 종료합니다.
- 잡몹 목록에는 기존 테스트 적과 `CaveScout.asset`을 연결했습니다. `BossBattle.asset`은 기존 테스트 유닛을 사용한 보스 웨이브 예시입니다. 이전 `EncounterBattle.asset`도 고정 전투 입력으로 사용할 수 있습니다.

- 파티 편성에서 각 캐릭터의 시작 무기를 선택합니다. 검=나이트, 활=아처, 단검=어쌔신, 스태프=캐스터, 오브=샤먼입니다. 탐사 진입 시 클래스가 고정되며 같은 클래스의 무기만 교체할 수 있습니다. 무기를 해제해도 고정 클래스는 유지되고, 탐사를 종료하면 제한을 해제합니다. Main의 PartyFormationController.startingWeapons가 시작 무기 목록입니다. HUD와 캐릭터 정보창에서 클래스를 확인할 수 있습니다.
